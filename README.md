# 凭借API Key 接进 QQ 的多模态阅读鲸鱼娘

仓库名是 `qq-bot-apikey-whale`。她带着 API Key，通过 OneBot v11 游进 QQ，能聊天、换人格、读文献，也能看图片和视频；群聊、私聊、主动发言和 B站都由你自己打开。

这是依据 2026-10-25 本地代码整理的独立发布副本。包含源码、离线测试、示例配置、小鲸鱼内在人格示例和可再分发的贴纸素材；没有原部署的账号、密钥、聊天记录或 Git 历史。没有附带 QQ 客户端、接入层或代理服务。

## 当前功能

- **聊天与模型**：OpenAI 兼容接口；主模型及提供方可切换。视觉可使用独立模型，或由管理员开启视觉同步，跟随主模型。同步不会让纯文本模型自动获得视觉能力。
- **人格与记忆**：内在人格与表达人格分开保存；切换风格保留共同记忆。风格增强让姓名、自称和称呼遵循当前角色。支持模型自主选择长期笔记，身份记忆与按聊天、发言者隔离的个人记忆分别管理，不等于保存全部聊天。
- **自然语言操作**：主模型可判断用户是在聊天还是请求操作，核对现有选项，再提出待确认建议；程序执行权限核验。直接指令仍可使用。
- **阅读**：支持群文件 PDF、TXT、Markdown，以及可抓取的文献网页。可主动挑选感兴趣的群文档，阅读后在当前上下文继续讨论。
- **续读与精读**：PDF 普通阅读按每 100 页窗口抽样；空闲时自动续读并保存进度。另有逐页精读，详细记忆有效 5 小时，之后按机制保留读后感和最多 3000 字的自选记忆。
- **视觉与媒体**：群内点名看图、私聊直接发图、主动模式下按额度留意群图；静态或动态 WebP、QQ 视频及视频文件可抽帧理解。视频不读取音轨。
- **主动参与**：每群独立开关，低频、标准、活跃三个档位，每日发言上限分别为 8、24、30 次；受概率、冷却、静默时段和上下文约束，不保证达到上限。主动阅读另有开关及频率；默认按真实 QQ 号排除官方 Q群管家，不让它触发主动接话。
- **B站与贴纸**：可选的字幕和真实画面采样、按兴趣找视频、主动浏览、账号登录、点赞评论；可按语境发送蓝鲸/黑鲸贴纸。
- **其他**：文件翻译、可选搜索与图片溯源、定时消息、群欢迎、发送防重和失败处理。

完整指令及群聊、私聊、全局的区别见 [COMMANDS.md](COMMANDS.md)。

## 安装和首次配置

需要 Python 3.11 或更新版本。视频抽帧另需安装 FFmpeg，确保 `ffmpeg`、`ffprobe` 可在运行环境找到。PDF 文字提取使用 pypdf，不需要安装桌面 PDF 阅读器。

在项目目录创建虚拟环境并安装依赖：

```sh
python -m venv .venv
```

Windows PowerShell 使用：

```powershell
.venv\Scripts\python.exe -m pip install -r app/requirements.txt
Copy-Item app/config.example.yaml app/config.yaml
```

Linux / macOS 使用：

```sh
.venv/bin/python -m pip install -r app/requirements.txt
cp app/config.example.yaml app/config.yaml
```

先安装并登录你选择的 OneBot v11 接入层，例如 SnowLuma 或 NapCat，再打开 `app/config.yaml`：

1. 填写 `admin_qq` 和真实的 `target_group_ids`，移除占位群号。
2. 设置 `napcat.ws_url`、`api_http_url`，分别填写 WS 和 HTTP 服务端的 token。`napcat` 是历史配置名，也用于兼容的其他 OneBot 接入层。
3. 在 `llm_providers.example` 填接口地址、密钥、模型列表，启用提供方；设置 `current_provider` 和 `current_model`，并将 `deepseek.enabled` 设为 `true`。`deepseek` 同样是通用聊天配置的历史名称，不限定厂商。
4. 设置 `deepseek.trigger_groups`；**空列表表示不限制群**。按需开启 `trigger_private`。初次接入建议只填写用于验收的群。
5. 如需图片理解，配置并开启 `qwen_vl`，或者由管理员开启视觉同步，使支持图片输入的主模型处理视觉。

从项目根目录运行：

```sh
python app/bot.py
```

也可以直接使用虚拟环境中的 Python。示例默认关闭 AI、私聊触发、定时发送、欢迎和 B站；主动模式初始未在任何群开启。模型密钥只能填写在你自己的 `config.yaml` 中。

## 模型、人格与权限

管理员由 `admin_qq` 决定，与 QQ 群管理身份无关。**修改模型、风格增强开关、视觉同步开关只允许管理员写入**；这些设置全局影响所有群与私聊。

当前实现允许普通用户使用“切换风格”，最终风格也是全局的。选择菜单显示当前值；选择和确认状态绑定发起人的 QQ 号及当前聊天，支持“取消”，约两分钟过期，换话题退出。菜单状态隔离不代表最终配置按群隔离。

示例内在人格是小鲸鱼的内在人格，位于 `app/personas/内在人格.txt`。角色风格位于 `app/prompts/*.txt`，仍是可替换的表达示例。两处都可以自行修改。修改 TXT 后，新请求会重新加载。风格增强关闭时仍使用现有的内外人格组合，开启后强化当前角色的姓名和称呼规则，不清空记忆。

自然语言请求的目标、权限和可用功能都需要程序校验。普通聊天回复不代表操作已经执行；待确认操作只能由同一个人在同一个聊天中确认。

## 定时和主动消息校验

这两条路径仅发送结构化结果中的最终台词，不发送 JSON 前的说明、推理字段或未校验的裸文本。异常结构、超长、未完成输出及明显的中英文风格盘算会被拒绝，最多一次内容重试，仍不合格就跳过；正常英文台词不因此被禁用。拒绝或 silent 不扣主动发言额度。定时发送和补发入口同样检查。

默认排除官方 Q群管家的真实发送者 ID，消息不进入主动上下文、不计数、不重置空闲计时。可用 `proactive.ignore_user_ids` 增加其他忽略账号，不按昵称过滤。详情及边界见 [PUBLIC_MESSAGES.md](app/PUBLIC_MESSAGES.md)。

## 阅读方式与预算

在群内上传文档后点名机器人，或者说“挑一份你感兴趣的文档读”。同类自然表达也可由主模型判断并提出确认。阅读并不自动等于读完整本书：

- 普通 PDF 阅读：从首个 100 页窗口中最多抽取 12 个页面片段；成功后，空闲约 30 秒可继续下一个窗口。结果应注明实际页码和抽样范围。
- 逐页精读：逐页处理 PDF 文字；支持暂停、继续、验收和进度查询。详细内容及笔记保留 5 小时，长期记忆是读后感和有限精选内容。
- 续读遇到点名、私聊、定时或主动消息时让出资源；空闲后从保存页码恢复。明确暂停或验收后需要恢复；连续失败也会暂停。
- 文档最大 64 MiB。解析进程的 CPU 预算为 90 秒、墙钟预算为 120 秒；阅读模型阶段总预算为 300 秒，包含最多一次重试，并非每次尝试各有 300 秒。
- 扫描件、插图、图表不属于当前 PDF 文字精读能力；没有文字层时需先 OCR。受保护网页、下载失败和接口超时仍可能使阅读失败，不能仅凭文件名声称读过。

## 图片代理和缓存

图片下载总预算为 55 秒，已有连接、首段和空闲超时及一次有限重试。`image_download.proxy_only: true` 表示严格走代理；代理不可用时失败，不回落直连。

没有专用配置时读取现有环境 HTTP 代理。可在 `image_download` 下设置 `image_proxy_url`，只覆盖图片下载的代理地址，支持 HTTP/HTTPS 代理及认证；它不会改写进程环境，也不会将模型 API、视频文件和文献 DoH 一起切换到该代理。错误的覆盖配置直接失败。项目不负责安装、订阅或启动代理服务。

图片缓存最多保留 1 小时，并受数量和容量限制；聊天文字和识图描述不会随缓存删除。下载的视频临时副本在抽帧后删除；采样画面在内存中最多保留 1 小时，可能提前淘汰，重启后失效。动态 WebP 最多采样 6 帧；视频最多采样 40 帧，每批 4 帧，每轮最多查看 3 批。它们都是画面采样，不是完整逐帧观看。

## B站与公开互动

先将 `bilibili.enabled` 开启，再按指令登录或使用链接读取。能否获取视频受网络、平台响应、字幕和账号权限影响，失败时不应称已看过。

“刷B站 开启 兴趣词”会启用该群的自动浏览，**同时启用自主点赞和评论**；使用前确认这是你希望的行为。可用“刷B站 互动关闭”单独关闭互动。点赞、评论会由登录账号真实执行，账号全局共用，各群开关独立。示例默认关闭 B站功能。
