# Word 文献阅读

`.docx` 已加入群文件选择、自然语言提要、上传预约、主动挑文档和文献追问的现有流程。上传后可点名要求“提供这份Word的提要”，不必更换另一套命令。

原生读取正文、表格可见文字、脚注及尾注；不启动 Office，不访问外部链接，不执行宏。删除的修订文字、隐藏文字、域指令和嵌入对象不作为正文。图片、图表、公式版面、页眉页脚及文本框不保证完整识别，不作 OCR。

Word 页码依赖排版环境，结果按文本段落定位；不会把 DOCX 段落冒充 PDF 页码。沿用文献正文与摘录预算，长文会标注部分摘录，不能称为全文精读。现有按100页续读和逐页精读仍针对 PDF；需要这些机制时可先转为带文字层 PDF。

旧 `.doc` 通过环境中安装的 `antiword` 读取。缺少时会明确提示安装解析器，或另存为 DOCX/PDF。DOCX 无需安装 python-docx、LibreOffice 或 antiword。Linux 常见的可选系统包名是 `antiword`；本更新没有自动安装系统软件，也没有实测这台 Windows 主机上不存在的旧DOC解析器。

解析仍在原有限时、限资源 worker 中执行；DOCX 额外限制解压体积、XML 大小和条目数，拒绝重复、越界或实体声明。文献大小上限仍为64 MiB，不改变下载和代理策略。

VM 安装器只合并 `paper_reader.py` 的文档提取函数、扩展名与帮助文字，保留现有 DoH/下载定制；遇到未知提取函数差异会停止，让操作者合并，不盲目覆盖。
