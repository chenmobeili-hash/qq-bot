# 定时与主动公开消息的输出边界

本次修复覆盖 `generate_timed_message`、`_generate_proactive`、定时发送入口与暂存补发。

## 结构化结果

模型只应返回两个字段：发送为 `{"kind":"send","reply":"最终台词"}`，不参与为 `{"kind":"silent","reply":""}`。仅 `reply` 能进入发送流程；推理字段、JSON 前的说明和外层包装不会作为消息发送。

使用现有模型路由和 JSON 兼容层。服务端明确返回“不支持 response_format”时可改用文本 JSON 协议，仍执行相同校验，不放宽为发送裸文本。该路径不允许操作或记忆字段，不会产生额外权限。

## 拒绝与重试

- 结构错误、重复字段、多个对象、额外字段、非字符串台词、超长或未完成输出均拒绝。
- 增加明显的中英文风格盘算、分析标记等检查，覆盖本次报告的两类内容。它是辅助检查，不是对所有可能语义的完美分类，也不是英文禁令。
- 内容不合格最多重试一次，第二次仍不合格就跳过。没有额外的模型审稿请求；整个主动生成共用 65 秒预算，定时生成共用 90 秒预算，均包含内容重试和格式协商。网络异常直接跳过。
- 定时台词最多 80 字，主动台词最多 160 字；超长重新生成或跳过，不再把未验收文本硬截成群消息。
- 日志只记录来源、类别、尝试次数和状态，不记录拒绝的原文。生成中切换模型或人格时放弃旧结果。

发送入口再次验证。只有验证过的定时消息能进入 HTTP 备用发送与补发队列；旧的无验证标记项直接丢弃。补发改写也使用同一协议；改写失败时只能使用先前已经验证的原消息。

主动结果拒绝或选择 silent 时，不发送、不扣主动发言每日额度，但保留原有尝试冷却，避免反复调用模型。主动识图尝试额度仍按原规则单独计算。

## 排除 Q群管家

默认在主动观察入口按真实发送者 QQ 号排除官方 Q群管家 `2854196310`，不依赖昵称。它的文字、图片和 @all 不进入主动上下文，不增加消息数、不重置空闲计时、不触发主动视觉或生成。

可在 `proactive.ignore_user_ids` 中再添加其他不希望用于主动接话的 QQ 号。这个列表是全局的主动观察排除项，默认 Q群管家排除始终保留；不是禁止用户手动对话的黑名单。同名普通群友不会因昵称被排除。已有真实群友触发的主动任务仍按原规则处理。
